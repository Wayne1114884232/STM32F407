## 使用步骤

1. 完整获取仓库，在 Keil 中打开上面的工程文件，保留原有相对目录。
2. 核对编译器、器件包、启动文件、晶振和目标板型号。
3. 在主程序和对应驱动头文件中确认启用的外设及 GPIO，再连接模块。
4. 执行 Rebuild，检查编译错误和警告；确认调试器与 Flash 算法后再下载。
5. 按主程序流程检查显示、串口或中断现象。涉及电机的工程，首次上电先架空车轮。

源码包含乱码注释，且本次未完成编译验证。首次使用应先检查主程序语法与源码编码，再核对 LCD/触摸驱动中的引脚宏。
